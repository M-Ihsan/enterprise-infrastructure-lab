# Screenshots and Diagrams

Use this folder for images that make the lab notes easier to understand. Prefer descriptive filenames, for example:

```text
2026-11-17-server-preparation.png
lab-network-topology.png
```

In the relevant notes page, link an image with a relative path, such as `![Lab topology](../screenshots/lab-network-topology.png)`.

Before adding an image, check that it does not expose credentials, tokens, personal information, product keys, public IP addresses, or sensitive organizational details. Only include material from systems and environments you own or are authorized to document.
